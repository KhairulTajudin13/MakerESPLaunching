Persona 1: The Beginner Learner

"See what your code is doing while you learn ESP32."

Target: First-time ESP32 Users, Students, New Makers
Survey Basis: 42% ESP32 Community Poll (Largest Segment)
RRP: RM39 (Launch Offer: ~20% Off pending approval)
Customer Goal Upload first program, understand GPIO, and progress to useful projects without wiring & driver frustration.
Main Frustration "My code uploaded, but I cannot tell what the board is doing or where the problem is."
Persona Promise Start with fewer setup barriers, understand electronic activity clearly, and build confidence one project at a time.
BEFORE · PROSPECTBOX 1
1. My Target Market
Who they are: First-time ESP32 users, students learning programming & electronics, new makers, Arduino-to-ESP32 switchers, teachers learning before teaching.
What they want: Successful first upload, easy GPIO experiments, clear examples, fewer wiring mistakes, simple troubleshooting, path beyond beginner exercises.
What they worry about: Driver installation, wrong COM port, upload failure, wrong board selection, loose USB, wiring errors, code vs hardware confusion, outgrowing the board.

2. My Message to My Target Market
Your First ESP32 Project Should Feel Clear, Not Confusing

  • Understand Better: 14 GPIO LEDs, RX/TX indicators, built-in button & buzzer.
  • Build Further: 8MB flash, Wi-Fi/Bluetooth, Maker Port, ESP32 ecosystem.
Buying Trigger: "I can start learning without buying and wiring every basic component first."
